# A Byte of Python

"A Byte of Python" 是一本免费的 Python 编程书籍。它面向初学者，可作为 Python 语言的教程或学习指南。如果你对电脑的了解仅限于如何保存文本文件，那么这本书就是为你准备的。

## 适用于 Python 3

本书将教你使用 Python 3。书中也会提供一些指导，帮助你适应更老但更普及的 Python 2。

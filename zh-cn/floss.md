# 附录：FLOSS {#floss}

> 注意：请注意本节写于 2003 年，所以其中一些内容对你来说可能有些古旧 :-)

"自由/开源软件"，简称 [FLOSS](http://en.wikipedia.org/wiki/FLOSS)，基于社区的概念，而社区本身基于分享的概念，特别是知识的分享。FLOSS 可以免费使用、修改和重新分发。

如果你已经阅读了本书，那么你已经熟悉 FLOSS 了，因为你一直在使用 *Python*，而 Python 就是一个开源软件！

以下是一些 FLOSS 的例子，让你了解社区分享和协作可以创造出什么样的东西：

[Linux](http://www.kernel.org)：这是一个用于 GNU/Linux 操作系统的 FLOSS 操作系统内核。Linux 这个内核是由 Linus Torvalds 在学生时期开始的。Android 基于 Linux。你如今使用的任何网站大多都在 Linux 上运行。

[Ubuntu](http://www.ubuntu.com)：这是一个由 Canonical 赞助的社区驱动的发行版，是当今最受欢迎的 GNU/Linux 发行版。它允许你安装大量的 FLOSS，而且所有这些都以易于使用和易于安装的方式提供。最棒的是，你可以直接重启计算机从 CD 运行 GNU/Linux！这允许你在将其安装到计算机上之前完全试用新的操作系统。不过，Ubuntu 并不完全是自由软件；它包含专有的驱动程序、固件和应用程序。

[LibreOffice](http://www.libreoffice.org/)：这是一个出色的社区驱动和开发的办公套件，包含文字处理器、演示文稿、电子表格和绘图组件等。它甚至可以轻松打开和编辑 MS Word 和 MS PowerPoint 文件。它几乎可以在所有平台上运行，并且是完全自由、开源的软件。

[Mozilla Firefox](http://www.mozilla.org/products/firefox)：这是_最好的_网页浏览器。它的速度极快，并因其合理而出色的功能获得了广泛好评。扩展概念允许使用任何类型的插件。

[Mono](http://www.mono-project.com)：这是 Microsoft .NET 平台的开源实现。它允许在 GNU/Linux、Windows、FreeBSD、Mac OS 和许多其他平台上创建和运行 .NET 应用程序。

[Apache 网络服务器](http://httpd.apache.org)：这是流行的开源网络服务器。事实上，它是这个星球上_最_流行的网络服务器！它运行着近一半以上的网站。是的，没错——Apache 处理的网站比所有竞争对手（包括 Microsoft IIS）加起来还要多。

[VLC 播放器](http://www.videolan.org/vlc/)：这是一个视频播放器，可以播放从 DivX 到 MP3 到 Ogg 到 VCD 和 DVD 的任何东西……谁说开源不好玩？;-)

这个列表只是为了给你一个简要的概念——还有更多优秀的 FLOSS，如 Perl 语言、PHP 语言、Drupal 网站内容管理系统、PostgreSQL 数据库服务器、TORCS 赛车游戏、KDevelop IDE、Xine 电影播放器、VIM 编辑器、Quanta+ 编辑器、Banshee 音频播放器、GIMP 图像编辑程序……这个列表可以一直列下去。

# 翻译指南 {#translation-howto}

1. 本书的完整源代码可以从 {{ book.sourceUrl }} 获取。
2. 请先 [fork 本仓库](https://help.github.com/articles/fork-a-repo)。
3. 然后，将仓库克隆到你的电脑上。你需要了解如何使用 [Git](http://www.git-scm.com) 来完成这一步。
4. 阅读 [Honkit 文档](https://honkit.netlify.app)，特别是 [Markdown 部分](https://honkit.netlify.app/syntax/markdown.html)。
5. 开始编辑 `.md` 文件，将其翻译为你的本地语言。
6. 参见 [INSTALL.md](https://github.com/swaroopch/byte-of-python/blob/master/INSTALL.md) 了解如何生成网站、PDF、EPUB。

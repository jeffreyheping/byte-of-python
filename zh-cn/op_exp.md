# 运算符与表达式 {% raw %}{#op-exp}{% endraw %}

你编写的大多数语句（逻辑行）都会包含_表达式_。表达式的一个简单例子是 `2 + 3`。一个表达式可以分解为运算符和操作数。

_运算符_是执行某种操作的功能，可以用 `+` 等符号或特殊关键字来表示。运算符需要一些数据来进行操作，这些数据被称为_操作数_。在这个例子中，`2` 和 `3` 就是操作数。

## 运算符

我们将简要介绍各种运算符及其用法。

请注意，你可以使用交互式解释器来计算示例中给出的表达式。例如，要测试表达式 `2 + 3`，请在交互式 Python 解释器提示符下输入：

```python
>>> 2 + 3
5
>>> 3 * 5
15
>>>
```

以下是可用运算符的快速概览：

- `+`（加）
    - 将两个对象相加
    - `3 + 5` 得到 `8`。`'a' + 'b'` 得到 `'ab'`。

- `-`（减）
    - 给出一个数减去另一个数的结果；如果第一个操作数缺失，则假定为零。
    - `-5.2` 得到一个负数，`50 - 24` 得到 `26`。

- `*`（乘）
    - 给出两个数相乘的结果，或返回字符串重复指定次数后的结果。
    - `2 * 3` 得到 `6`。`'la' * 3` 得到 `'lalala'`。

- `**`（幂）
    - 返回 x 的 y 次幂
    - `3 ** 4` 得到 `81`（即 `3 * 3 * 3 * 3`）

- `/`（除）
    - 用 x 除以 y
    - `13 / 3` 得到 `4.333333333333333`

- `//`（整除）
    - 用 x 除以 y，并将结果_向下_取整到最近的整数值。请注意，如果其中一个值是浮点数（float），你将得到一个浮点数结果。
    - `13 // 3` 得到 `4`
    - `-13 // 3` 得到 `-5`
    - `9//1.81` 得到 `4.0`

- `%`（取模/求余）
    - 返回除法的余数
    - `13 % 3` 得到 `1`。`-25.5 % 2.25` 得到 `1.5`。

- `<<`（左移）
    - 将数字的位向左移动指定的位数。（每个数字在内存中用位或二进制数字表示，即 0 和 1）
    - `2 << 2` 得到 `8`。`2` 用二进制表示为 `10`。
    - 向左移动 2 位得到 `1000`，即十进制的 `8`。

- `>>`（右移）
    - 将数字的位向右移动指定的位数。
    - `11 >> 1` 得到 `5`。
    - `11` 用二进制表示为 `1011`，向右移动 1 位后得到 `101`，即十进制的 `5`。

- `&`（按位与）
    - 数字的按位与运算：如果两个位都是 `1`，则结果为 `1`，否则为 `0`。
    - `5 & 3` 得到 `1`（`0101 & 0011` 得到 `0001`）

- `|`（按位或）
    - 数字的按位或运算：如果两个位都是 `0`，则结果为 `0`，否则为 `1`。
    - `5 | 3` 得到 `7`（`0101 | 0011` 得到 `0111`）

- `^`（按位异或）
    - 数字的按位异或运算：如果两个位（`1` 或 `0`）相同，则结果为 `0`，否则为 `1`。
    - `5 ^ 3` 得到 `6`（`0101 ^ 0011` 得到 `0110`）

- `~`（按位取反）
    - x 的按位取反结果是 -(x+1)
    - `~5` 得到 `-6`。更多详情请参考 http://stackoverflow.com/a/11810203

- `<`（小于）
    - 返回 x 是否小于 y。所有比较运算符都返回 `True` 或 `False`。请注意这两个名称的首字母大写。
    - `5 < 3` 得到 `False`，`3 < 5` 得到 `True`。
    - 比较可以任意链式组合：`3 < 5 < 7` 得到 `True`。

- `>`（大于）
    - 返回 x 是否大于 y
    - `5 > 3` 返回 `True`。如果两个操作数都是数字，它们会先被转换为共同的类型。否则，它总是返回 `False`。

- `<=`（小于等于）
    - 返回 x 是否小于或等于 y
    - `x = 3; y = 6; x <= y` 返回 `True`

- `>=`（大于等于）
    - 返回 x 是否大于或等于 y
    - `x = 4; y = 3; x >= 3` 返回 `True`

- `==`（等于）
    - 比较两个对象是否相等
    - `x = 2; y = 2; x == y` 返回 `True`
    - `x = 'str'; y = 'stR'; x == y` 返回 `False`
    - `x = 'str'; y = 'str'; x == y` 返回 `True`

- `!=`（不等于）
    - 比较两个对象是否不相等
    - `x = 2; y = 3; x != y` 返回 `True`

- `not`（布尔非）
    - 如果 x 是 `True`，则返回 `False`。如果 x 是 `False`，则返回 `True`。
    - `x = True; not x` 返回 `False`。

- `and`（布尔与）
    - `x and y`：如果 x 是 `False`，则返回 `False`，否则返回 y 的值
    - `x = False; y = True; x and y` 返回 `False`，因为 x 是 False。在这种情况下，Python 不会去计算 y 的值，因为它知道 `and` 表达式左侧已经是 `False`，这意味着无论其他值如何，整个表达式都会是 `False`。这被称为短路求值（short-circuit evaluation）。

- `or`（布尔或）
    - 如果 x 是 `True`，则返回 `True`，否则返回 y 的值
    - `x = True; y = False; x or y` 返回 `True`。这里同样适用短路求值。

## 数学运算与赋值的快捷方式

对一个变量执行数学运算，然后将运算结果赋值回该变量，这是很常见的操作，因此有一种快捷写法：

```python
a = 2
a = a * 3
```

可以写成：

```python
a = 2
a *= 3
```

注意，`var = var operation expression` 变成了 `var operation= expression`。

## 求值顺序

如果你有一个表达式如 `2 + 3 * 4`，是先做加法还是先做乘法？我们高中的数学知识告诉我们应该先做乘法。这意味着乘法运算符的优先级高于加法运算符。

下表给出了 Python 的运算符优先级表，从最低优先级（最弱绑定）到最高优先级（最强绑定）。这意味着在给定的表达式中，Python 会先求值表中靠下的运算符和表达式，再求值靠上的。

下表摘自 [Python 参考手册](http://docs.python.org/3/reference/expressions.html#operator-precedence)，为了完整性而提供。更好的做法是使用括号来适当地对运算符和操作数进行分组，以明确指定优先级。这使得程序更加易读。详情请参见下面的[改变求值顺序](#changing-order-of-evaluation)。

- `lambda`：Lambda 表达式
- `if - else`：条件表达式
- `or`：布尔或
- `and`：布尔与
- `not x`：布尔非
- `in, not in, is, is not, <, <=, >, >=, !=, ==`：比较运算，包括成员测试和身份测试
- `|`：按位或
- `^`：按位异或
- `&`：按位与
- `<<, >>`：移位
- `+, -`：加法和减法
- `*, /, //, %`：乘法、除法、整除和取余
- `+x, -x, ~x`：正号、负号、按位取反
- `**`：幂运算
- `x[index], x[index:index], x(arguments...), x.attribute`：下标、切片、调用、属性引用
- `(expressions...), [expressions...], {key: value...}, {expressions...}`：绑定或 tuple 显示、list 显示、dict 显示、set 显示

我们尚未遇到的运算符将在后面的章节中解释。

具有_相同优先级_的运算符在上表中列在同一行。例如，`+` 和 `-` 具有相同的优先级。

## 改变求值顺序 {% raw %}{#changing-order-of-evaluation}{% endraw %}

为了使表达式更易读，我们可以使用括号。例如，`2 + (3 * 4)` 肯定比 `2 + 3 * 4` 更容易理解，因为后者需要了解运算符优先级的知识。和其他所有东西一样，括号应该合理使用（不要过度使用），并且不应该冗余，比如 `(2 + (3 * 4))`。

使用括号还有一个额外的好处——它帮助我们改变求值顺序。例如，如果你想让加法在乘法之前求值，那么你可以写成 `(2 + 3) * 4`。

## 结合性

运算符通常从左到右结合。这意味着具有相同优先级的运算符按从左到右的顺序求值。例如，`2 + 3 + 4` 的求值顺序是 `(2 + 3) + 4`。

## 表达式

示例（保存为 `expression.py`）：

```python
length = 5
breadth = 2

area = length * breadth
print('Area is', area)
print('Perimeter is', 2 * (length + breadth))
```

输出：

```
$ python expression.py
Area is 10
Perimeter is 14
```

**工作原理**

矩形的长和宽存储在同名变量中。我们利用这些变量，通过表达式来计算矩形的面积和周长。我们将表达式 `length * breadth` 的结果存储在变量 `area` 中，然后使用 `print` 函数打印它。在第二种情况下，我们直接在 `print` 函数中使用表达式 `2 * (length + breadth)` 的值。

另外，请注意 Python 是如何_美观地打印_输出的。即使我们没有在 `'Area is'` 和变量 `area` 之间指定空格，Python 也会自动为我们添加，这样我们就能得到干净漂亮的输出，程序也因此更加易读（因为我们不需要担心输出字符串中的空格问题）。这就是 Python 如何让程序员的生活变得更轻松的一个例子。

前言

序言

Python 可能是少数既简单又强大的编程语言之一。这对初学者和专家来说都是一件好事，更重要的是，用它编程非常有趣。本书旨在帮助你学习这门美妙的语言，并展示如何快速而轻松地完成任务——可以说是"你编程问题的解药"。

本书适合谁

本书是 Python 编程语言的指南或教程。它主要面向编程新手，对有经验的程序员也同样有用。

本书的目标是：如果你对计算机的了解仅限于如何保存文本文件，那么你可以通过本书学习 Python。如果你有编程经验，你也可以通过本书学习 Python。

如果你确实有编程经验，你会对 Python 与你最喜欢的编程语言之间的差异感兴趣——我在书中突出了许多这样的差异。不过要提醒你，Python 很快就会成为你最喜欢的编程语言！
